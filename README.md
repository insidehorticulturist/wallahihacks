## Installation

To install or set up this repository:

1. Install Pesde [here](https://docs.pesde.dev/installation/):
2. Run `pesde install` in this directory
    - Alternate ways you can do is by opening this repository in Visual Studio Code and open up your terminal then run `pesde install` either whichever way is best for you.
3. When you set it up you have to build the code by running `./build.bat`
4. Once the command is run a code labeled **dist.lua** will pop up in the directory which is the bundled code.
